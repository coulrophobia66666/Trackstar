Medien-Trimmer

Datei laden, abspielen/vor- und zurückspulen, an der gewünschten Stelle "Start hier setzen" bzw. "Ende hier setzen" klicken – wie Ein-/Auspunkte in einem Schnittprogramm. Danach direkt in eine der Sektionen übernehmen, statt Sekundenzahlen zu raten.

Musik-Short

Der einfache Weg: nur Bild + Musik + gewünschter Ausschnitt → fertiger Hochkant-Short. Ohne Bild wird automatisch eine animierte Wellenform generiert.


      

    


    

      

        
Bild-Generator Neu

        
Lokale KI-Bildgenerierung (Stable-Diffusion-Derivat, läuft auf diesem Rechner). Kein API-Key, keine Tokens, keine Kontingent-Grenzen – dafür ohne GPU spürbar langsam (grob 1–5 Minuten pro Bild) und mit dem Qualitätsniveau eines kleinen, offline-tauglichen Modells statt eines großen Cloud-Dienstes.

      

      

        
Einmaliges Setup nötig, bevor das hier funktioniert: pip install --index-url https://download.pytorch.org/whl/cpu torch und pip install -r requirements-imagegen.txt in der aktivierten .venv (siehe README, Abschnitt "Lokale KI-Bildgenerierung"). Erster Aufruf lädt zusätzlich einmalig das Modell aus dem Netz (mehrere hundert MB).
