2. Wie diese Website mit deinen Daten umgeht

Dein hochgeladener Track

Der Kurzcheck und die Tiefenanalyse (Frequenzen, Lautheit, Dynamik) laufen vollständig lokal in deinem Browser ab. Die Audiodatei wird zu keinem Zeitpunkt auf einen Server hochgeladen oder gespeichert – sie verlässt dein Gerät nicht.

Songtitel und Songtext

Nur wenn du aktiv auf „KI-Einschätzung anzeigen" klickst, werden Songtitel, Songtext und die berechneten technischen Kennzahlen (z. B. Lautstärke-Score) an unseren Server (Cloudflare Worker) und von dort an den KI-Anbieter Anthropic (Claude) übermittelt, um eine Einordnung, Titel-Ideen und einen überarbeiteten Songtext zu erzeugen. Diese Übertragung erfolgt nur auf deinen aktiven Klick hin, nicht automatisch.

Ziel-Sender / Ziel-Playlist

Eine optionale Texteingabe, die ausschließlich lokal zur Anzeige der Ergebnisse verwendet wird.

Für die KI-Einschätzung (Textanalyse, Titel-Ideen, Textüberarbeitung) nutzen wir die API von Anthropic (Claude). Die dafür übermittelten Texte werden gemäß der Datenschutzerklärung von Anthropic verarbeitet.
